# val

Exercícios de programação em C para a faculdade (UFRJ).

## Conteúdo

- **[Lista 1](Lista%201/README.md)** — minha resolução. Chamadas de sistema para
  manipulação de arquivos: `open`, `read`, `write`, `lseek`, `ftruncate`,
  `stat`, `fstat`, `lstat`.
- **[Lista 1 - alt](Lista%201%20-%20alt/README.md)** — resolução da mesma lista
  feita por [Robson Duarte](https://github.com/RobsDuarte/Learning-Linux),
  guardada aqui para comparação. Inclui uma
  [conferência exercício por exercício](Lista%201%20-%20alt/COMPARACAO.md)
  entre as duas versões.

## Compilando

Na minha `Lista 1` os binários não vão pro repositório — entre na pasta do
exercício e rode `gcc exN.c -o exN`. Instruções detalhadas, saída esperada e
como recriar cada arquivo de teste estão no README de cada lista.
